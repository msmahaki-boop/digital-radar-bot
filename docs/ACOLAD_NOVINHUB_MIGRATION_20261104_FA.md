# مهاجرت کنترل‌شده آکولاد از Buffer به NovinHub

## قطعی
- در تاریخ ۱۴ آبان ۱۴۰۵ (۴ نوامبر ۲۰۲۶) نسخه زنده Telegram Bot طبق رسید `PUBLISHED msg_id=46` ارسال کرده است.
- Buffer برای اینستاگرام امروز پست `6aead890e478396c274412ec` را با وضعیت `scheduled` ساعت ۱۸ تهران ثبت کرده بود.
- نوین‌هاب با کلید موجود در GitHub حساب‌های Instagram `230527` و Telegram `233472` را در GET /account برگرداند، بدون نیاز به ورود مجدد.
- مسیر تصویر در این شاخه: GPT Image 2 از API GapGPT، سپس Gemini 2.5 Flash Image، سپس Qwen 2.1، بعد Pexels در صورت وجود Secret، بعد Wikimedia Commons با CC0/Public Domain و تطابق متنی، در نهایت فقط متن.
- برای خروجی استاندارد **پنج‌اسلایدی فعلی**، تصویر فقط در اسلاید ۲ و ۴ مجاز است. اگر مدل بی‌ربط تولید کند، بررسی انسانی لازم است.

## فعال‌سازی
- پس از تست کامل و رفع اشکال نوین‌هاب، Workflow جدید `.github/workflows/acolad-novinhub-instagram-daily.yml` هر روز ساعت ۱۴:۱۱ تهران خروجی خبری معتبر را می‌سازد و برای ساعت ۱۸:۰۰ در نوین‌هاب زمان‌بندی می‌کند.
- Workflow قبلی Buffer از حالت schedule خارج می‌شود اما `workflow_dispatch` برای بازگشت حفظ می‌گردد. پست Buffer امروز **لغو نمی‌شود**.
- جریان تلگرام فعلاً با ربات اثبات‌شده و قفل ضدتکرار ادامه دارد؛ جابه‌جایی انتشار تلگرام به نوین‌هاب بدون جایگزین قفل eight-slot خطر تکرار و قطع سرویس دارد. تست اتصال/پیش‌نویس نوین‌هاب انجام می‌شود ولی انتشار موازی آن روشن نمی‌شود.
- اگر Buffer یا نوین‌هاب برای همان روز پستی داشته باشند، نسخه جدید `SKIP` می‌کند.
- متغیرها و Secrets موجود عوض نشده‌اند. `GAPGPT_API_KEY` و یکی از `NOVINHUB_API_TOKEN`، `NOVINHUB_TOKEN` یا `NOVINHUB_ACCESS_TOKEN` استفاده می‌شود. کلید در فایل و لاگ نیست.

## معیار موفقیت
- `NOVINHUB_SCHEDULE_CREATED_NOT_PUBLISHED` همراه شناسه پست، تاریخ دقیق UTC و داشتن ۵ PNG معتبر.
- پس از ساعت انتشار، GET /post و مشاهده واقعی در اینستاگرام لازم است. تیک سبز GitHub، Draft و Queue با Published تفاوت دارند.
- تلگرام `PUBLISHED + msg_id` باید ثبت شده باشد.

## rollback
- بازیابی نسخه پیش از ادغام از commit `feebbea5085ba74936e128a51bfcd143fb5c64b2` برای Workflowهای اصلی؛ حذف cron workflow جدید و بازگرداندن cron قدیمی Buffer.
- اگر نوین‌هاب پستی ساخته باشد، قبل از بازگشت و روشن‌کردن Buffer وضعیت آن پست را بررسی کن تا دو انتشار ایجاد نشود.
