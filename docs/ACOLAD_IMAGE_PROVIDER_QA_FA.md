# آزمایش امن تصویرسازی آکولاد — ۴ نوامبر ۲۰۲۶

این تغییر **فقط پیش‌نمایش** است. روی شاخه جداگانه قرار دارد. Workflowهای فعال تلگرام، اینستاگرام، Buffer، Cloudinary و NovinHub تغییر نکرده‌اند.

## تشخیص مبتنی بر لاگ واقعی
- آزمایش GapGPT با مدل `gpt-image-1-mini` در Run 41615384558 خطای HTTP 429 داشت. دیدن مدل در /models تضمین سهمیه یا اعتبار نیست.
- خروجی چندصحنه‌ای Run 41647095390 با مدل محلی ساخته شد، ولی یک ایده تصویر برای چهار صحنه تکرار شد.
- بسته ۴ نوامبر: `image_api_calls:0` و `stock_status:DISABLED`. بنابراین تأیید تولید با API ابری یا کاربرد استوک نیست.
- در Run 41741192235 موتور استوری به علت کمبود چهار خبر مستقلِ معتبر (۲ قدیمی + ۲ جدید) توقف امن کرد؛ این مشکل جدا از تصویر است.

## راهکار این شاخه
`acolad_image_provider_qa.py` یک پرامپت اختصاصی از واقعیت خبر و ایده هر صحنه می‌سازد؛ در صورت تأیید صریح و وجود Secret جداگانه `OPENAI_API_KEY` فقط یک درخواست به API رسمی OpenAI می‌فرستد. پاسخ 429 یا نبود تصویر واقعی به جای تصویر جعلی، گزارش خطا می‌شود. مسیر استوک Pexels با `PEXELS_API_KEY` صرفاً لینک و مشخصات گزینه را برای بررسی انسانی ثبت می‌کند؛ بدون دانلود یا استفاده خودکار. هر عکس استوک «نمادین» است، نه عکس واقعه.

## قدم ۱: تست بدون API و بدون هزینه
- در GitHub شاخه `fix/acolad-image-provider-qa-20261104` را باز کن؛ Workflow اصلی را تغییر نده.
- اجرای تست: `python -m unittest discover -s tests -p 'test_acolad_image_provider_qa.py' -v`
- خروجی معتبر: ۷ تست PASS؛ بدون درخواست پولی و بدون انتشار.

## قدم ۲: پس از بررسی خروجی و مجوز پرداخت مستقل
- Secrets را فقط در GitHub → Settings → Secrets and variables → Actions اضافه کن؛ **کلید را در چت/README/کد نفرست**.
- برای تست یک تصویر از API رسمی: `OPENAI_API_KEY`، و برای یافتن استوک: `PEXELS_API_KEY` (هر کدام اختیاری).
- یک فایل JSON به نام `brief.json` با `article_fact` (واقعیت با منبع)، `scene_idea` (استعاره هر صحنه)، `stock_query` بساز.
- اجرای بدون هزینه: `python acolad_image_provider_qa.py --brief brief.json --output acolad_image_provider_qa`.
- **فقط با مجوز صریح پرداخت**: `python acolad_image_provider_qa.py --brief brief.json --approval ONE_IMAGE_API_TEST_APPROVED`.
- نتیجه: `provider_status.json` و فقط در صورت پاسخ معتبر `concept_preview.png`. خروجی نیازمند تأیید زیبایی‌شناختی است.

## خطر و بازگشت
- `main` دست‌نخورده؛ برای بازگشت شاخه و PR را کنار بگذار یا ببند؛ هیچ تغییری در Secretهای موجود ایجاد نشده.
- API رسمی با حساب و اعتبار API مستقل از اشتراک ChatGPT کار می‌کند؛ موجودی و محدودیت هزینه را پیش از آزمایش کنترل کن.
- این آزمایش نه Buffer را queue می‌کند، نه draft می‌سازد و نه به کانال‌ها می‌فرستد.
- برای اتصال واقعی به Pipeline پس از دیدن یک تصویر خوب، PR دوم با Preview و بررسی دستی جداگانه لازم است.
