# راهنمای آزمایش استوری کامل آکولاد

**هدف:** یک تلاش Gemini 2.5 Flash Image از GapGPT؛ تنها در صورت پاسخ HTTP 503 یک تلاش GPT Image 2. سپس ۸ فریم نمونه فرضی آکولاد در خروجی محلی. بدون API Buffer، تلگرام، اینستاگرام، نوین‌هاب یا Cloudinary؛ بدون Draft بیرونی و بدون Publish.

**گیت‌ها:** کلید موجود `GAPGPT_API_KEY`، شناسایی هر دو مدل در GET /models، تأیید دستور اجرای یک‌باره در شاخه تست، تست mock بدون انتشار، نبود حلقه تکرار. نتیجه `status.json` نشان می‌دهد چه مدلی واقعاً فراخوانی شده؛ `IMAGE_VERIFIED` یعنی تصویر دریافت و بررسی شده، نه اینکه زیبا یا مناسب انتشار است.

**هزینه:** قیمت ۰٫۰۴ دلار برای Gemini از تصویر پنل کاربر آمده؛ برای GPT Image 2 نرخ ثابت به‌ازای درخواست از پنل معلوم نیست و قیمت توکنی دارد. سقف ۲۰ هزار تومان **محدودکننده قطعی صورتحساب نیست**؛ هزینه نهایی باید از حساب GapGPT بررسی شود. اگر دو درخواست اجرا شوند هر دو بالقوه پولی‌اند.

**قصه:** `examples/acolad_story_full_draft_20261104.json` درباره شخصیت فرضی مهدی است؛ هیچ عدد علمی یا خبر اثبات‌نشده را به خبر واقعی تبدیل نکرده‌ایم. تصویرِ موفق به فریم‌های صحنه دوم اضافه می‌شود، بقیه از زمینه رسمی برند استفاده می‌کنند. `frames/story_01.png` تا `story_08.png` خروجی واقعی پیش‌نویس‌اند. این پیش‌نویس داخل GitHub Artifact است نه Buffer Draft.

**معیار تأیید:** فایل‌های PNG 1080×1920، سالم‌بودن ۸ فریم و تغییرناکردن پیکسل‌های قبل در هر صحنه، تطبیق تصویر با متن و بازبینی انسانی. پس از این آزمایش هیچ‌چیز به صورت خودکار در شبکه اجتماعی منتشر نمی‌شود.

**بازگشت:** هیچ فایل Workflow اصلی یا `main` عوض نشده؛ کافی است PR آزمایشی ادغام نشود.
