## مرز وضعیت‌ها
- `PREVIEW_VALIDATED_NO_WRITES`: **انتشار نشده**.
- `SKIPPED_EDITORIAL_QA_NO_GOOD_STORY`: سوژه/متن به کیفیت نرسیده؛ پست نساز و ادعای ارسال نکن.
- `SCHEDULED_PROVIDER_CONFIRMATION_NOT_PUBLISHED`: فقط زمان‌بندی در نوین‌هاب با شناسه و بازخوانی پذیرفته شده؛ هنوز منتشر نشده.
- `PUBLISHED_PROVIDER_AND_EXTERNAL_ID`: سرویس وضعیت ارسال و شناسه بیرونی را تأیید کرده؛ مشاهده واقعی کاربر همچنان کنترل نهایی است.
- «تیک سبز» GitHub یا `Draft` یا `Scheduled` هیچ‌کدام رسید انتشار واقعی نیست.

## ریسک‌ها و شفافیت
- تست GitHub روی شاخه آزمایشی و بدون انتشار واقعی انجام می‌شود؛ هنوز ارسال `is_draft=0` و `is_scheduled=1` در سه شبکه در این نسخه از ابتدا تا انتها تأیید نشده است.
- در هر خطای فنی، قطع اتصال، سقف API، کاهش کیفیت یا نبود خبر معتبر: **توقف امن**؛ هیچ متن ساختگی یا تکراری به زور منتشر نمی‌شود.
- GitHub Actions امکان تأخیر Cron دارد. اگر اجرا بعد از پنجره امن رسید، پست را عقب نینداز یا تصادفی برای فردا نذار؛ `SAFE_SCHEDULING_WINDOW_MISSED`.
- مدل‌های ارزیاب خودکار جای سردبیر انسانی را در قضاوت ذوقی نمی‌گیرند؛ رضایت دوره‌ای باید کنترل شود.
- هزینه Luna و تصویر API متغیر است؛ عدد فاکتور قطعی در لاگ وجود ندارد؛ سقف تلاش تصویر ۸ درخواست در هر روز و متن Luna تا ۴ درخواست پژوهش + ۳ درخواست بازنویسی/نقد دارد.
