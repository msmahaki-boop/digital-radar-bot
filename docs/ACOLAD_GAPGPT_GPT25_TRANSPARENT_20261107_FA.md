# آکولاد | تصویرسازی واقعی GPT Image 2.5 با PNG شفاف — ۷ نوامبر ۲۰۲۶

## جمع‌بندی مستند چهارشنبه ۴ نوامبر
- اجرای GitHub Actions شماره **41812181131** مدل `gpt-image-2` را از API گپ‌جی‌پی‌تی فراخوانی کرد: یک خروجی واقعی PNG تأیید شد، اما درخواست‌های بعدی 403 شدند و سیستم سراغ Qwen رفت.
- تصویرسازی توافق‌شده **دارای یک لایه مستقل بدون پس‌زمینه** بود؛ متن فارسی و لوگو روی **قالب رسمی خود آکولاد** توسط موتور رندر اضافه می‌شوند.
- این مسیر را نباید با تولید یک پوستر نهایی در API تصویر اشتباه گرفت.

## ایراد کشف‌شده در نسخه فعلی
- سند `image_provenance.json` بسته ۷ نوامبر نشان می‌داد `original_procedural: true` و `model_generated: false`، یعنی طرح‌های قابل‌مشاهده محصول برنامه Pillow بودند، نه مدل تصویرساز.
- `gpt-image-2.5-sunburst` و `gpt-image-2.5-flare` در GET مدل‌های GapGPT فهرست شدند، اما هر دو در تولید واقعی HTTP 403 دادند.
- اجرای تشخیصی **42391027067** کد قطعی `pre_consume_token_quota_failed` و نوع `gap_api_error` را ثبت کرد. مشکل به سهمیه/مجوز مصرف **همان کلید** مرتبط است؛ فهرست‌شدن مدل به معنای امکان مصرف نیست.

## فایل‌های جدید، بدون تخریب نسخه فعال
- `acolad_gapgpt_transparent_art.py`: تولید API واقعی با مدل `gpt-image-2.5-sunburst`، `background=transparent`، `output_format=png` و اعتبارسنجی آلفا؛ هیچ جایگزین ساختگی ندارد.
- `acolad_gpt25_strict_renderer.py`: ترکیب تک‌تک PNGهای واقعی با قالب برند آکولاد. تصویرسازی بدون پس‌زمینه در لایه‌ای جداگانه نگهداری می‌شود.
- `acolad_gapgpt_transparent_preview.py`: پیش‌نمایش مجزای ۷ اسلاید از محتوا و نمرات سردبیری تأییدشده؛ **هیچ مجوز NovinHub ندارد**.
- `acolad_v4_daily_autopublish.py`: فقط در صورت `ACOLAD_REQUIRE_REAL_GPT25_ART=1` از موتور جدید استفاده می‌کند؛ بدون این پرچم، رفتار نسخه فعال تغییر نمی‌کند.
- `acolad_narrative_visual_v2.py`: هنگام دریافت فایل PNG واقعاً شفاف، ماسک آلفای اصلی را حفظ می‌کند.
- `tests/test_acolad_gapgpt_transparent_art.py` و `tests/test_acolad_gpt25_strict_renderer.py`: رد تصویر سفید فاقد آلفا، رد HTTP403، ممنوعیت fallback ساختگی، اعتبارسنجی مسیر.

۱. در **پنل خود GapGPT**، سهمیه مصرفِ کلید ذخیره‌شده در GitHub Secret `GAPGPT_API_KEY` را برای مدل‌های GPT Image 2.5 بررسی و اصلاح کنید. کلید را در پیام، فایل یا لاگ قرار ندهید. فقط در صورت نیاز آن را از `GitHub → Settings → Secrets and variables → Actions` به‌روزرسانی کنید.
