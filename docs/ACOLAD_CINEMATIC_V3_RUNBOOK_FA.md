# آکولاد ــ راهنمای موتور استوری سینمایی V3 (۱۴۰۵/۰۸/۱۲)

## وضعیت تأییدشده
- مخزن: `msmahaki-boop/digital-radar-bot`، شاخه `main`.
- کد ایزوله: `acolad_narrative_visual_v2.py`، نمونه: `examples/acolad_narrative_v2_fixed_demo.json`.
- کیفیت: فونت واقعی `assets/fonts/IRANSans-*.ttf`، وسط‌چین، اندازه کوچک‌تر، هایلایت قلم‌مویی پنج‌رنگ، متن افزوده‌شونده بدون جابه‌جایی پیکسل‌ها.
- روایت: اسلاید دوم «آمار بازدید سایت بالاست / ولی **سبد خریدها خالیه!** 🤔».
- ۱۲ تصویر خروجی در GitHub run 41615384558؛ تست‌های رایگان ۷+۵ موفق.
- مدل تصویری آزمایشی در GapGPT: `gpt-image-1-mini`، ابعاد 1024×1536، کیفیت low، فرمت PNG، ترجیح پس‌زمینه شفاف.
- نتیجه واقعی درخواست تصویری: **HTTP 429**، بنابراین **هیچ تصویر مفهومی توسط API تولید نشد**. دلیل قطعی 429 از لاگ موجود قابل تشخیص نیست (ممکن است محدودیت سرعت، اعتبار یا سهمیه باشد). هیچ پرداخت قطعی از گزارش اثبات نشده.
- قیمت برآوردی به نرخ عمومی OpenAI برای مدل/کیفیت: خروجی 0.006 دلار + ذخیره احتیاطی 0.006 دلار برای متن و حاشیه = 0.012 دلار ≈ **۳٬۰۰۰ تومان**. قیمت GapGPT و برداشت واقعی تأیید نشده و سقف ۲۰٬۰۰۰ تومان **سقف سخت کیف پول نیست**.
- امنیت: ۰ Draft نوین‌هاب، ۰ صف، ۰ انتشار تلگرام یا اینستاگرام. Workflowهای قبلی انتشار فعال بدون تغییر.
- Workflow تصویر بعد از تست یک‌باره به حالت `workflow_dispatch` با عبارت موافقت صریح برگشت؛ هیچ Push خودکاری آن را دوباره پولی اجرا نمی‌کند.

## سیاست تصاویر مفهومی
برای توالی چندقابی، پس از هر ۲ تا ۳ قاب متن یا تغییر صحنه، یک تصویر مفهومی **اصیل** از نقاشی خطی نامتقارن و استعاری، با فضای خالی و بدون کپی اثر یا امضای هنرمند، در نظر گرفته می‌شود. طراحی از متن جداست: متن همیشه با ایران‌سنس روی تصویر برند قرار می‌گیرد و لوگوی دقیق و بدون تغییر آکولاد حفظ می‌شود.
اولویت PNG شفاف؛ اگر خروجی مات بود، پس‌زمینه روشنِ یکپارچه و تبدیل امن به شفاف با کنترل بصری. خروجی‌های فاقد عکس به‌طور مستقل ادامه دارند.
فایل‌های مفهومی پس از تولید موفق در `acolad_concept_assets/scene_02.png`، `scene_04.png`، `scene_06.png` قرار می‌گیرند. صرف وجود فایل، تأیید ارتباط معنایی با خبر نیست؛ بازبینی انسانی لازم است.

## معیار موفقیت و بازگشت
- متن قبلی باید **پیکسل به پیکسل ثابت** بماند؛ تست `previous_pixels_identical=true`.
- متن و تصویر باید با هم‌معنایی درست و منبع قابل‌دفاع بررسی شوند.
- برای هزینه واقعی، رسید کیف پول GapGPT لازم است، نه صرفاً برآورد اسکریپت.
- برای لغو تغییرات، فقط Commitهای V3 روی `acolad_narrative_visual_v2.py` و فایل مثال `examples/acolad_narrative_v2_fixed_demo.json` را برگردانید؛ از دست‌زدن به Workflowهای انتشار فعال خودداری کنید.
- تست NovinHub Draft جدا از پیش‌نمایش، فقط با مجوز انتشار اثر بیرونی اجرا شود؛ موفقیت Workflow به معنی Draft/Published نیست.
