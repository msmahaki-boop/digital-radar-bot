# تحریریه روزانه و استوری تصویری آکولاد — V1

**وضعیت تاریخ ۱۴۰۵/۰۸/۱۲ (۲۰۲۶/۱۱/۰۳) — خروجی GitHub واقعی، بدون انتشار**

## ۱) آنچه روی مخزن main نصب و اجرا شده
- `acolad_daily_editorial_v1.py`: جمع‌آوری سرنخ‌های روز از هفت محور اقتصاد/معیشت ایران، پلتفرم‌ها، هوش مصنوعی، فناوری، بازاریابی/برند، شبکه‌های اجتماعی، رشد کسب‌وکار؛ چرخش فرم شروع قصه؛ نگهداری سطح شاهد، تاریخ و لینک هر منبع.
- `.github/workflows/acolad-daily-editorial-v1.yml`: فقط تحقیق بدون هزینه هر روز در `03:45 UTC` (حدود **۰۷:۱۵ تهران**)، artifact شامل `intake.json` و `DAILY_BRIEF_FA.md`. هیچ پیام، Draft و صف انتشار فعال نمی‌کند.
- تولید خودکار **متن داستان Luna** فقط وقتی `ACOLAD_DAILY_LUNA_PREVIEW_ENABLED=true` صریحاً به‌صورت Repository Variable ثبت و هزینه روزانه تأیید شود؛ پیش‌فرض خاموش است. هنگام فعال‌شدن سقف برنامه‌ریزی هر روز `$0.018 ≈ ۴۵۰۰ تومان` در نرخ `۲۵۰٬۰۰۰ تومان/دلار` (سقف سخت پرداخت در GapGPT نیست). در صورت نبود **زوج خبر واقعی + پژوهش دارای چکیده مرتبط** مدل حتی فراخوانی نمی‌شود.
- `acolad_concept_art_pipeline_v2.py`: مسیر یک‌درخواستِ کنترل‌شده Gemini 3.1 Flash Lite Image (فقط اجرای دستی با مجوز)، در صورت خطا نقاشی مفهومی اصیل و شفاف بدون سرویس خارجی. تصویرها به جای ایجاد قاب اضافی، روی صحنه‌های معنادار قرار می‌گیرند. مدلِ تصویر خودکارِ روزانه در حالت Scheduled **غیرفعال** است تا 429 و هزینه تکراری نداشته باشیم.
- `acolad_narrative_visual_v2.py`: همان ایران‌سنس واقعی، وسط‌چین، هایلایت قلمی چندرنگ، پس‌زمینه و لوگوی دقیق آکولاد، متن افزوده‌شونده و فریز پیکسلی آزموده‌شده.
- `examples/acolad_new_daily_episode_guest_checkout_20261103.json`: سناریوی مستقل ۱۲ استوری درباره «خرید بدون ثبت‌نامِ مخفی»، بدون بازنویسی ماجرای مهدی.
- `tests/test_acolad_daily_editorial_v1.py`, `tests/test_acolad_editorial_gate_v1.py`: بررسی تنوع هوک، ۷ محور، عدم اختراع منبع/هزینه در نبود شاهد، PNG شفاف و فاصله صحنه‌ها.

## ۲) شواهد اجرا
- اجرای اول: https://github.com/msmahaki-boop/digital-radar-bot/actions/runs/41620592587
  - ۱۹ منبع نامزد تحریریه جمع‌آوری شدند، اما **صفر زوج خبر تازه و مقاله علمیِ مرتبط** به گیت سخت‌گیرانه رسید. این به معنی بی‌خبر بودن دنیا نیست؛ فقط اجازه ادعای ارتباط ساختگی نمی‌دهد.
  - خروجی نمونه ۱۲ تصویر، ۶ صحنه، ۴ PNG مفهومیِ **برنامه‌نویسی‌شده** (نه خروجی موفق AI)، تست فریز پیکسل = `true`.
  - درخواست تصویر Gemini `gemini-3.1-flash-lite-image` با HTTP 429 روبه‌رو شد؛ **یک بار تلاش**، بدون Retry. قیمت مرجع رسمی حدود `$0.0336 ≈ ۸۴۰۰ تومان` برای ۱K؛ برداشت واقعی کیف پول معلوم نیست.
- اجرای نهاییِ کاملاً رایگان پس از اصلاح ارتباط نقاشی با قصه: https://github.com/msmahaki-boop/digital-radar-bot/actions/runs/41621922293
  - **۱۹ تست رایگان موفق** (۲ + ۱۰ + ۷)، ۱۲ استوری بازتولید و ۴ تصویر PNG شفاف بدون API پولی
  - `previous_pixels_identical=true`؛ `novinhub_draft_count=0`؛ `published=0`.
- Workflow یک‌بارهٔ رایگان پس از تست حذف شد؛ تنها Run و Artifact آن برای ممیزی باقی است.

## ۳) منبع واقعی داستان مهمان
1. Baymard 2026: https://baymard.com/lists/cart-abandonment-rate — درصد ۱۸٪ مربوط به پاسخ‌های خریداران آنلاین آمریکا پس از کنارگذاشتن صرفاً گشت‌وگذار است؛ علت گزارش‌شده، نه اثر اثبات‌شده راه‌حل.
2. Baymard account-selection benchmark: https://baymard.com/checkout-usability/benchmark/step-type/account — حدود ۴۴٪ از سایت‌های بنچمارک، یافتن خرید مهمان را بی‌دلیل دشوار می‌کردند. این درصدِ سایت‌هاست نه کاربران.
3. Baymard delayed registration: https://baymard.com/research-articles/delayed-account-creation — پیشنهاد انتقال ثبت‌نام اختیاری به بعد از ثبت سفارش، بدون ادعای افزایش قطعی فروش.

## ۴) اصول ایمنی و راه بازگشت
- Secrets هیچ‌کجا لاگ یا فایل نشده‌اند. فعال‌کردن نوین‌هاب و Buffer/تلگرام در این نسخه **صفر** است؛ هیچ Workflow فعال انتشار قدیمی بازنویسی نشده.
- متن، گزاره و عکس تولیدشده در حالت **PREVIEW/HUMAN REVIEW** هستند؛ تیک سبز به معنی Published نیست.
- چنانچه مشکل تازه رخ داد، Workflow `.github/workflows/acolad-daily-editorial-v1.yml` را از شاخه `main` حذف یا غیر‌فعال کنید. این کار Workflowهای فعال قبلی را تغییر نمی‌دهد. سایر فایل‌های جدیدِ جداگانه را می‌توان با Revert Commit در GitHub به وضعیت قبلی بازگرداند.
- برای افزایش پایداری AI تصاویر، به‌جای تکرار 429 از روش شفافِ محلی استفاده می‌کنیم؛ انتخاب مدل دیگر فقط پس از مشاهده تعرفه و سلامت اتصال و با مجوز هزینه.
- برای فعال‌سازی **تولید روزانه پولی**، ابتدا درخواست تأیید سقف هزینه دوره‌ای لازم است؛ `ACOLAD_DAILY_LUNA_PREVIEW_ENABLED` باید فقط پس از این تأیید فعال شود. انتشار روزانه جداگانه مجوز می‌خواهد.
